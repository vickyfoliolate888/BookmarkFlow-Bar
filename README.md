## 🔧 Troubleshooting Common Issues

Even the best tools can have a hiccup. Here are a few solutions if something isn't working right.

**Issue: The extension won't load.**
- **Solution:** Double-check that you turned on **"Developer mode"** in `chrome://extensions`. Make sure you selected the correct folder that contains the `manifest.json` file. Sometimes, you have to select the main folder, not a sub-folder.

**Issue: My bookmarks are not showing up in the bar.**
- **Solution:** First, try refreshing your current page. If they still don't appear, open a new tab. The extension needs a moment to read your browser's bookmark data. If it persists, try removing and re-adding the extension.

**Issue: The keyboard shortcut doesn't work.**
- **Solution:** The shortcut might be conflicting with another extension or a browser feature. You can change it! Go to `chrome://extensions`, click on **"Keyboard shortcuts"** at the bottom of the left menu, and reassign a new key combination for BookmarkFlow-Bar.

**Issue: The bar doesn't appear on certain websites.**
- **Solution:** Some websites (like the Chrome Web Store or internal Chrome pages) are restricted and don't allow extensions to run. This is a browser security feature and not a bug in the extension.
